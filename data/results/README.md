# Registered result files

These files are schema-only placeholders. Registered experiment scripts will
replace them with tidy observations. Do not type aggregate results directly
into the manuscript or plotting code.

- `detection_repair.csv`: one row per case, method, and stochastic seed.
- `resource_efficiency.csv`: one row per case and layer-loading condition.
- `task_outcomes.csv`: one row per case, task level, method, and seed.

The figure and table production rules are defined in
`docs/figure-table-plan.md` and `paper/figures/figure-specs.yaml`.
